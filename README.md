1. Мета роботи
Зчитати просторові дані (датасет) із файлу, налаштувати графічне полотно (canvas) розміром рівно 960540 пікселів у декартовій системі координат (початок у нижньому лівому куті, вісь X праворуч, вісь Y вгору) та зберегти результат у графічному форматі.
2. Використані технології
Мова програмування: Python 3.x
Бібліотека візуалізації: Matplotlib
3. Хід виконання
Створено скрипт для побустрокового зчитування координат (X,Y) з файлу DS1.txt.
За допомогою параметрів figsize=(9.6, 5.4) та dpi=100 сформовано полотно точним розміром 960×540 пікселів.
Застосовано обмеження осей ax.set_xlim(0, 960) та ax.set_ylim(0, 540) для забезпечення декартової системи координат із початком у нижньому лівому куті.
Збережено візуалізацію у файл зображення result_km_51fpm_101.png.
4. Висновки
Практичну роботу успішно виконано. На основі вхідного файлу датасету згенеровано точне графічне полотно заданого розміру із правильним розташуванням осей координат. Результати збережено у форматі PNG.
